# 得正 (Dejeng) Oolong Tea Project - 레시피 트레이닝 퀴즈 웹앱

得正(Dejeng) 오롱티 프로젝트 매장 직원을 위한 모바일 최적화 레시피 암기 및 실전 시험 웹애플리케이션입니다.

## ✨ 주요 기능
- **실제 라벨 스티커 100% 동일 구현**: 매장 포스 라벨 프린터에서 출력되는 실제 스티커 디자인 반영 (로고, 폰트, 배치 일치)
- **공식 시트 순서 빈칸 채우기**: 공식 레시피 순서(크리머, 파우더, 시럽, 티, 얼음 등)에 따른 수량 입력 방식 (단위 제외 숫자 전용)
- **특수 규칙 및 쇼튼 폼(Shorten Form) 자동 연산**:
  - **L사이즈 + 토핑**: M사이즈 기본 레시피 자동 적용
  - **M사이즈 + 토핑**: 공식 감량 변환표(Shorten Form) 기준에 맞춘 자동 연산 및 변환 내역 제공
- **모바일 완벽 최적화**:
  - 스마트폰 키보드 터치 시 소수점(`.`) 포함 숫자 패드 전용 모드
  - 화면 하단 전용 모바일 가상 번호패드 탑재 (`1~9`, `0`, `.`, `⌫`, `전체삭제`, `채점하기`)
- **실시간 자동 채점 & 정답 해설**: 정답/오답 즉시 시각화 및 쇼튼 변환 전/후 수치 비교
- **공식 레시피 원본 및 쇼튼표 팝업 제공**

- 스마트폰(iOS Safari, Android Chrome, 카카오톡 인앱 브라우저) 및 데스크톱 모든 브라우저 지원

## 📊 스프레드시트에서 퀴즈 앱(링크)으로 업데이트하는 방법
1. 구글 스프레드시트 상단 메뉴 [확장 프로그램] -> [Apps Script]로 이동
2. `google_apps_script.js` 파일의 코드를 복사하여 붙여넣고 [저장 (💾)]
3. 스프레드시트 새로고침(F5) 후 상단에 생성된 `[🚀 퀴즈 앱 링크 업데이트]` -> `[🚀 [지금 클릭] 최신 레시피를 퀴즈 앱 링크로 즉시 반영]` 클릭
4. 시트 내에 버튼을 삽입한 뒤 스크립트(`sendRecipesToQuizApp`)를 할당하여 원클릭으로도 업데이트 가능합니다.
5. 이제 퀴즈 앱 링크에 접속하면 수정된 최신 레시피가 자동으로 출제됩니다.
